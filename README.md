# 格物志（gewuzhi）

> **框架作者**：伏羲 | **当前版本**：v1.4.0

日用消费品通用研究分析技能——格物致知，志以沉淀。

## 主要用途

把日常消费品研究中反复多轮的对话，沉淀为一次跑完的结构化分析。适用于以成分/原理/参数为区分度的实体消费品（家居耗材、工具五金、个护日化、美妆护肤、食品保健、厨具、服饰纺织、小家电等）的选型、评估、解惑与偏好反查类问题。

不覆盖医疗、投资、房产汽车等高客单价决策与服务类消费（转交对应专业模块）。

## 分析工作流框架简介

**结构：软框架 + 硬门槛**——硬门槛保下限（安全、置信度、可执行结论），软框架留发挥（透镜自选组合）。

```
Step 0   切入识别：品类 → 从大到小 / 单品 → 从小到大 / 问题 → 方案枚举
         （含混合形态、品牌全家桶追问、非交互豁免）
Step 0.5 历史检索：查品类缓存有无主文档；有历史时 L1 顺序隔离（先分析后读）/ L2 子代理盲审
路径内   六维分析透镜（原理类型/成分参数/场景匹配/安全边界/品牌格局/使用维护）
         + 偏好翻译机制（主观偏好 → 客观指标 → 成分配比；加工维度单列）
执行深度 内部自动路由（用户零认知负担）：
         小问 → 单线程；轻档研究 → 并行搜索子代理+主代理自查；全档研究（健康/大额）→ 并行搜索+红队复核
共用后段 安全红线检查（标准号反查/无国标转化/监管记录）→ 置信度自评（T1-T4 证据源 × 独立印证数）→ 历史比对
产出     前台速读版（含版本签名）+ 品类主文档更新 + HTML 渲染覆盖
沉淀     品类主文档制：一品类一活文档（最新结论速览 + 专题章节 + 更新记录），缓存只作索引
```

**三条思维原则**：贵 ≠ 好；大牌 ≠ 适合；概念 ≠ 功效。

**设计要点**：
- 软框架+硬门槛：透镜是引导性参考视角，硬门槛是不可豁免的验收项
- 殊途同归：切入点不同，最终收敛到同一张分析全景
- 置信度双因子：证据源分级 × 独立印证数，打在单条结论上
- 防锚定双档：L1 顺序隔离为纪律约束，L2 零上下文子代理盲审为真隔离
- 默认并行+红队：研究型任务自动多路搜索 + 独立挑刺，软文矩阵在首研即被拦截；子代理只返回不写盘，主代理汇总裁决（裁决阶梯 + 安全分歧就高不就低）
- 主文档制：知识以品类为单位持续生长，更新记录只增不删，历史由记录区 + git 双兜底

**成本声明**：研究型任务的并行+红队默认结构，token 消耗约为单线程 3-6 倍、耗时约 1.5-2 倍（搜索段并行，汇总→红队→裁决串行）。老大可随时一句指令降回单线程默认。

**回顾点**：满 5-10 个真实研究型任务后回顾红队采纳率（主文档更新记录里有度量），若采纳率为 0 则红队降为条件触发。

详细框架与执行规则见 [SKILL.md](./SKILL.md)。
