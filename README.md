# 格物志

> **框架作者**：伏羲 | **当前版本**：v1.3

日用消费品通用研究分析技能——格物致知，志以沉淀。

## 主要用途

把日常消费品研究中反复多轮的对话，沉淀为一次跑完的结构化分析：

- **选型**：「免钉胶有哪些类型，怎么选」「酱油怎么选」
- **评估**：「3M 免钉胶怎么样，有没有更好的」「Swisse 钙片值不值」
- **解惑**：「下水道堵了怎么办」「防晒霜防水防汗怎么选」
- **偏好反查**：「喜欢不透肉/顺滑/柔软/不反光的丝袜，需要什么成分、占比多少」

覆盖家居耗材、工具五金、个护日化、美妆护肤、食品饮料与保健品、厨具材质、服饰纺织、小家电等百元~千元级实体消费品。不覆盖医疗（→家庭医生）、投资（→挖掘机）、房产汽车等高客单价决策。

## 分析工作流框架简介

**结构：软框架 + 硬门槛**——硬门槛保下限（安全、置信度、可执行结论），软框架留发挥（透镜自选组合）。

**工作流：殊途同归**

```
Step 0   切入识别：品类 → 路径A（从大到小）/ 单品 → 路径B（从小到大）/ 问题 → 路径C（方案枚举）
         （含混合形态、品牌全家桶追问、非交互豁免）
Step 0.5 历史检索：查品类缓存有无主文档；有历史时 L1 顺序隔离（先分析后读）/ L2 子代理盲审
路径内   六维分析透镜（原理类型/成分参数/场景匹配/安全边界/品牌格局/使用维护）
         + 偏好翻译机制（主观偏好 → 客观指标 → 成分配比；加工维度单列）
共用后段 安全红线检查（标准号反查/无国标转化/监管记录）→ 置信度自评（T1-T4 × 印证数）→ 历史比对
产出     前台速读版（含版本签名）+ 品类主文档更新（一品类一活文档）+ HTML 渲染覆盖
沉淀     知识库/品类缓存.md = 索引（9 个一级分类）；研究报告/{分类}/{品类}.md = 知识本体
```

**三条思维原则**：贵 ≠ 好；大牌 ≠ 适合；概念 ≠ 功效（T4 源可转化为避坑素材）。

详细框架与执行规则见 [SKILL.md](./SKILL.md)。
